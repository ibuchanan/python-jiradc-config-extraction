# Jira Data Center OpenAPI specification

The checked-in `jira_software_dc_11.2.1_swagger.v3.json` is the OpenAPI 3.0.1 specification downloaded from:

<https://dac-static.atlassian.com/server/jira/platform/jira_software_dc_11002_swagger.v3.json>

The URL filename contains `11002`, but the document metadata declares Jira Software Data Center version `11.2.1`; the local filename follows the declared version. The spec contains 288 paths. Do not replace it with Jira Cloud's OpenAPI document: Cloud and Data Center APIs differ.

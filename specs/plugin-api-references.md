# Jira Data Center plugin API and configuration references

Reference for locating vendor documentation relevant to scoping an Elements Connect + ScriptRunner + Dynamic Forms rewrite for Jira Cloud. These links describe **Data Center** products; check the customer's installed app versions before relying on a version-specific export. Access checked 2026-11-03.

| Plugin | Vendor documentation | What it covers for this investigation |
| --- | --- | --- |
| Elements Connect | [API guide](https://doc.elements-apps.com/elements-connect/api-guide), [REST API guide](https://doc.elements-apps.com/elements-connect/elements-connect-rest-api), [SwaggerHub REST spec v2.0](https://app.swaggerhub.com/apis-docs/ElementsConnect/elements-connect/2.0) ([v1.0, deprecated](https://app.swaggerhub.com/apis-docs/ElementsConnect/elements-connect/1.0)) | Published REST API is for generating rendered HTML content for a field in an issue (issue view, navigator, XML export), **not an inventory of field or datasource configurations**. Do not conflate the app's REST API with external REST datasources it consumes. |
| Elements Connect | [Field configuration](https://doc.elements-apps.com/elements-connect/field-configuration), [administration guide](https://doc.elements-apps.com/elements-connect/administration-guide), [backup and restore](https://doc.elements-apps.com/elements-connect/backup-restore) | Individual field configurations can be downloaded as JSON; the administration Import / Export area offers configuration backups and anonymized support dumps. Confirm backup contents and secret handling before using them for analysis. |
| ScriptRunner for Jira DC | [Script Registry](https://docs.adaptavist.com/sr4js/latest/features/script-registry/), [Configuration Exporter](https://docs.adaptavist.com/sr4js/latest/features/built-in-scripts/configuration-exporter/) | Script Registry exports scripts and configured features in ZIP/JSON plus an inventory CSV, including project mappings; documented for 8.54+, 9.19+, 10.0+. Earlier 9.x releases excluded workflow functions; [9.20 added them](https://docs.adaptavist.com/sr4js/latest/release-notes/release-9.x/). Configuration Exporter is a built-in script producing configuration-as-code snippets, not a REST inventory API. No published OpenAPI spec for enumerating installed ScriptRunner configuration was located. |
| Dynamic Forms for Jira (Deviniti) | [Import and export](https://deviniti.com/support/addon/server/dynamic-forms/latest/import-export/), [Fields Visibility](https://deviniti.com/support/addon/server/dynamic-forms/latest/dynamic-forms/), [Bundled Fields configuration](https://deviniti.com/support/addon/server/dynamic-forms/latest/bundled-fields-configuration/) | Fields Visibility configuration can be exported to JSON in the admin UI. The same export is accessible through the documented Java `ExportConfigurationService.exportAsJsonString()` / `exportToJsonFile()` methods (example uses ScriptRunner); this is **not a REST endpoint**. Verify whether Bundled Fields and other features are covered separately. No published OpenAPI configuration-inventory spec was located. |

**Interpretation:** The Elements Swagger spec exists, but none of the three identified REST surfaces provides a documented, complete read-only inventory of installed configuration. The linked exports are potentially richer evidence for field references, behavior conditions, scripts, project mappings, and datasource dependencies; their coverage must be validated against the installed versions. Absence of an identified public REST inventory API is not proof that no version-specific/internal route exists. Treat configuration backups and scripts as sensitive; they may contain credentials or connection details.

The current exporter’s [coverage notes](../packages/cli/README.md) describe the Jira records already collected and the unsupported app-config stages. An `unsupported` stage is **unknown coverage**, not evidence of no plugin usage.
